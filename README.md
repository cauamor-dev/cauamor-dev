## 🚀 Projetos

O portfólio tem mais detalhes de cada um: [cauamor-dev.github.io](https://cauamor-dev.github.io/)

**Ecos da Última Aurora** (em desenvolvimento)
Jogo que estou criando em C# e Unity, com sistemas de gameplay, HUD e testes automáticos. O repositório ainda é privado.
`C#` · `Unity`

**[ContosoPizza API](https://github.com/cauamor-dev/contoso-pizza-api)**
API de estudo em C# e ASP.NET Core (.NET 10), baseada em um módulo do Microsoft Learn. Tem CRUD de pizzas com controller e service e 14 verificações HTTP documentadas.
`C#` · `ASP.NET Core` · `.NET 10`

**[Prazo](https://github.com/cauamor-dev/prazo)**
Controle de alimentos por validade. Mostra o que vence em até três dias, tem filtros, histórico de consumo e descarte, exportação em CSV e testes automatizados.
`Python` · `Flask` · `SQLite`

**[ShotFinder](https://github.com/cauamor-dev/ShotFinder)**
Busca de filmes e séries com elenco, onde assistir e lista de favoritos. Refiz a interface, criei a API em Node.js e acrescentei testes automatizados.
`React` · `Node.js` · `Express`

**[PUC News](https://github.com/cauamor-dev/Puc-News)**
Portal de notícias da faculdade, com busca, favoritos e gerenciamento de conteúdo usando uma API simulada.
`JavaScript` · `Bootstrap` · `Chart.js` · `JSON Server`
